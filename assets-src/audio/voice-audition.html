Ticket 0043 · Round 1 · Free tools

Which tool should voice the game?

Four free tools read the same Chapter 1 lines. Each tool designed its own voices from the same written description, so the character is the same brief in every column. Listen for acting, for whether a character still sounds like one person from line to line, and for whether Hollis and Harl sound like different men.

These are first takes with no retakes. No accent was asked for, and the tool's choice of accent is not final. Every clip is at the same volume. A script check confirmed the long lines say the right words, but nobody has listened to these yet.

The tools

All four are free and run on your graphics card, so there's no monthly bill. Each one's license allows selling the game with these voices and charges no royalties. If none is good enough, round 2 adds ElevenLabs (about $6 for Chapter 1, $66–$99 for the whole game) and Gemini (about $1, $14–$27).
