Visions of Shuyi: story preview

The writer's script preview: it plays the scenes of your .dlg files in the
game's own text box, with its faces and its music, and plays a file again
as soon as you save it.

Start it: double-click story-preview.exe in the folder that holds your
dialogue folder (a copy of the writer's repository has it at its root), or
drag the dialogue folder (or one .dlg file) onto story-preview.exe. Keep
the music folder next to it: the music is loaded from there.

The first key you press asks for a layout of keys (right- or left-handed,
as the game does); the line at the bottom of the window names them. Its tabs: Scenes
(pick one to play it), Switches (send away a character the scene's @if
blocks test, so the @else lines play; make the lead female or give them a
12-letter name), Lines (play from any text box, or from the line number you
type) and Problems (what story-check finds, with the file and the line).
While a scene plays, the strip at the top shows the file, the line, how the
line is said and each face's expression. The Unit info key lists every name
token with the name it shows, and every character's id and expressions.

HOW-TO-OPEN.txt says what to do the first time Windows stops the program.

LICENSE is the game's own license (proprietary: this copy is for trying out
scenes for the game, and may not be passed on). NOTICES.txt lists every
third-party work in this build, with its license text. THIRD_PARTY_ASSETS.md
credits the music and the font; their licenses are in audio-licenses/.
