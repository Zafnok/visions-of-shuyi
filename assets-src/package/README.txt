Visions of Shuyi

Windows: double-click visions-of-shuyi.exe. No installation needed. Keep
the music folder next to it: the game's music is loaded from there.

Linux: run ./visions-of-shuyi from a terminal (mark it executable first if
the archive extractor didn't preserve that: chmod +x visions-of-shuyi).
Keep the music folder next to it: the game's music is loaded from there.

macOS: open visions-of-shuyi.app. The music is inside the app.

Web: serve this folder with any static file server and open index.html,
e.g.: python -m http.server 8000, then http://localhost:8000

HOW-TO-OPEN.txt, on Windows and macOS, says what to do the first time the
system stops the game.

LICENSE is the game's own license (proprietary; see it for what you may and
may not do with this copy). NOTICES.txt lists every third-party work in this
build, with its license text. THIRD_PARTY_LICENSES.html and the other
*LICENSE* files cover open-source components used to build the game.
THIRD_PARTY_ASSETS.md credits the music, sounds and font; their licenses are
in audio-licenses/.
