# Asset sources

Inputs to the asset tools. Nothing here is embedded in the game; the tools
write their output into `assets/`.

| Path | What | Tool |
| ---- | ---- | ---- |
| `fonts/ter-u16n.bdf` | Terminus Font 4.49.1, 8×16 medium (OFL-1.1, see `assets/fonts/Terminus-LICENSE.txt`), unmodified | `cargo shuyi font-atlas` → `assets/fonts/atlas.{png,ron}` |
| `fonts/ter-u16b.bdf` | Terminus Font 4.49.1, 8×16 bold, the same release and license, unmodified: the bold of key caps (ticket 0254) | the same command, after `--bold` |
| `fonts/fusion-pixel-12px-monospaced-zh_hans.bdf` | Fusion Pixel Font 2026.11.10, 12px monospaced, Simplified Chinese (OFL-1.1, see `assets/fonts/FusionPixel-LICENSE.txt`); its glyphs unmodified, its `FONTBOUNDINGBOX` widened to the 16×16 wide cell (ticket 0236, `assets/fonts/README.md`) | the same command, after `--wide zhhans=` |
| `fonts/pad-shapes.bdf` | Our own glyphs added to the atlas: the PlayStation buttons' shapes `✕ ◯ □ △` (ticket 0220, `assets/fonts/README.md`) | the same command, passed after the font |
| `fonts/Cinzel-Bold.ttf`, `fonts/Cinzel-Medium.ttf` | Cinzel (OFL-1.1, see `assets/fonts/Cinzel-LICENSE.txt`) at weights 700 and 500: static instances of Google Fonts' `Cinzel[wght].ttf`, made with `python -m fontTools.varLib.instancer Cinzel[wght].ttf wght=700` (and `wght=500`). The chapter title card's lettering (ticket 0812, ADR-0128) | `cargo xtask lettering` → `assets/title/chapter_{name,line}.{png,ron}` |
| `audio/import.py` | Downloads and converts the chosen third-party music and sounds (ticket 0214, ADR-0027; originals git-ignored, see `audio/README.md`) | `python assets-src/audio/import.py` → `music/*.ogg`, `assets/audio/sfx/*.ogg` |
| *(none: made in code)* | The sprite test image, 16×16 (ticket 0231, `assets/images/README.md`) | Its tool was deleted (ticket 0191): `git show 61d537d2:crates/xtask/src/test_card.rs` wrote `assets-test/images/test_card.png` |
| *(none: made from `terrain.ron`, `classes.ron`, the palette and the font atlas)* | The sprite map skins' test tilesets: 24×24 tiles (ticket 0433), unit sheets shaped like the bought map sprites (ticket 0436), and 16×16 tiles with layers and looks, shaped like the bought tileset (ticket 0437); `assets/tilesets/README.md` | `cargo xtask test-tileset` → `assets-test/tilesets/test.{png,ron}`, `assets-test/tilesets/test_units.ron` and `test_units/*.png`, `assets-test/tilesets/test_auto.{png,ron}` |
| `tilesets/tiny_tales.ron` | The mapping: which bought Tiny Tales tile, or Tiled terrain of a bought sheet, each of our terrains and each layer is drawn with, for each look (ticket 0437, ADR-0052). Ours: names and numbers, no art. The bought sets it reads are in the private assets (ADR-0040) | `cargo xtask tileset-import` → `assets-private/game/tilesets/tiny_tales.{png,ron}` (`--list` prints the mapping) |
| *(none: made from the palette)* | The effect arrows, 14×7 (ticket 0436), and the map's edge arrows, 42×13 (ticket 0449); `assets/images/README.md` | Their tools were deleted (ticket 0191): `git show 61d537d2:crates/xtask/src/effect_marks.rs` wrote `assets/images/effect_marks.png`, `git show 90f97cf4:crates/xtask/src/edge_marks.rs` wrote `assets/images/edge_marks.png` |
| `title/logo.txt` | The title logo as text: a character a pixel, each a palette colour (ticket 0811, ADR-0059, `assets/title/README.md`). Ours | `cargo xtask title-art` → `assets/title/logo.png` and the placeholder backdrops beside it (those from the palette alone) |
| `audio/sound-audition.html` | The listening page Nick chose the game's sounds on (ticket 0020, `docs/design/audio.md`). Its Web Audio code is the recipe for the sounds we make ourselves: menu move B, select L, cancel B, dodge `miss:quick` (W2), heal HE5 | `cargo xtask sfx` → `assets/audio/sfx/*.wav` (`--check` only verifies the committed files; a test runs it) |
