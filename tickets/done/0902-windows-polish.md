# 0902 — Windows polish

## Context

A Steam/itch Windows game should launch without a console window, show a
proper icon in Explorer and the taskbar, and toggle fullscreen with the
standard keys.

## Nick input

**Sign-off** on the icon (show 2–3 options rendered at 32×32 and 256×256).

## Implementation steps

1. `#![cfg_attr(all(windows, not(debug_assertions)), windows_subsystem = "windows")]` in `app/src/main.rs`.
2. Icon: design 2–3 options in the game's style (e.g. a glyph from the font on a
   coloured background, generated by `cargo xtask icon` from the atlas so it's
   reproducible) → Nick picks → `assets/icon/icon.ico` (16/32/48/256) + PNGs.
3. Embed icon + version info (`FileDescription`, `ProductName`,
   `FileVersion` from Cargo) via `winresource` in `app/build.rs` **only when
   the target is MSVC and the resource compiler is available**; on the GNU host
   skip with a `cargo:warning` (Nick's machine has no `windres`/MSVC).
4. Runtime window icon via macroquad `Conf.icon` (all platforms).
5. `F11` and `Alt+Enter` toggle fullscreen (handled in `app`, reflected in
   Settings from 0805 if merged).

## Acceptance criteria

- [x] Release exe from CI: no console window, icon visible in Explorer, version info in Properties → Details.
- [x] Local GNU build still works (icon step skipped with a warning).
- [x] Fullscreen toggle works on Windows and web.

## Completion notes

- `windows_subsystem = "windows"` in release builds on Windows (no console).
- `cargo xtask icon preview <dir>` draws three options (hero `@` gold on
  navy, `†` white on crimson, `♦` teal on violet) at 32 and 256 px from the
  font atlas; `cargo xtask icon build <n>` writes `assets/icon/` (`icon.ico`
  with 16/32/48/256, `icon-{16,32,64}.png`). **Option 1 (hero) is the
  placeholder shipped** until Nick signs off; changing it is one command and
  regenerating. Note option 2 reads as a cross.
- `app/build.rs` embeds the icon and version info with `winresource`
  (a Windows-host build dependency, MIT) on MSVC targets only; the GNU host
  prints a `cargo:warning` and skips. The window icon comes from
  `Conf.icon`, on every platform.
- `F11` and `Alt+Enter` flip the Fullscreen setting (`Game::toggle_fullscreen`),
  so Settings shows it and it is saved. They are the window's own keys,
  read in `app/src/keys.rs`, not in the keymap, so they can't be rebound.
- Not verified here: the MSVC resource step and the web fullscreen toggle
  (no MSVC locally; the browser needs a click or key to allow fullscreen,
  which F11 is). CI's release build covers the exe.
- *Claude's starting rules*: none about gameplay.
