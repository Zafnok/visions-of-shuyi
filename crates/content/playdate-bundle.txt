# What the Playdate build leaves out of `assets/` (ticket 1036, ADR-0082).
#
# `build.rs` embeds every file under `assets/` in the Playdate's bundle but
# those listed here, and tells the bundle which it left out
# (`bundle::left_out`), so a loader can tell "left out on purpose" from
# "missing". A line is a path under `assets/`: a file (`icon/icon.ico`), a
# folder and everything below it (`audio/sfx/`). A line that matches no file
# stops the build. No build embeds a `README.md` (ADR-0105).
#
# A test plays Chapter 1 through the front end against this bundle
# (`crates/playdate/src/chapter_1.rs`): every file the game reads must be
# in it, and every file in it must be read. So a new file under `assets/`
# the Playdate never reads fails that test until it is listed here.
#
# This list never changes the PC and web builds.

# License texts; the game never reads them.
NOTICES-game.txt
audio/licenses/
fonts/Terminus-LICENSE.txt

# The PC's window and taskbar icons (the Playdate's card and icon are
# 1052's, in the `.pdx`).
icon/

# The sound effects: the Playdate plays its own copies, which its build
# converts and packs in the `.pdx` beside the game (ticket 1047,
# ADR-0084). `audio/audio.ron` stays: the game's scenes and battles name
# its cues, and the Playdate's player reads their files and volumes.
audio/sfx/
