## Themes

### The Act 1 critical path lost out to self-generated work

I sorted the 100 PRs into lanes. 47 went to writer-hire, privacy, release and legal work, about 16 to tooling and engine adoption, and 10 to pin moves. Lanes A, B, D and E (systems, content and the Playdate) got none. Only one Phase 3 PR (#623) and one Lane C PR (#621) landed. Ready critical-path tickets went untouched all week: 0852-0854, 1065, 1090, 0606, 0334 and the Playdate perf tickets 1057, 1068 and 1078. The five Lane I balance decisions (0079-0084) were also never raised with Nick. Meanwhile pin reviews filed about 17 adoption tickets and 12 of them were done the same week. 53 of the 81 tickets closed in the window were filed inside it. Nothing ranks work against 1064's blocker chain.

### Moving content to the private repo left CI checking the wrong things

After 0156-0160 (#651-#676), CI path filters and checks still point at the old public paths. playtest-levers.sh and demo.yml's paths ignore assets-private.rev, so #731 played only by accident. The voice-clip and disclosure tests return silently because CI never checks voice/ out. The private_assets:: load test runs only after merge. 192 skip guards make local runs without content look green. Two binaries that embed the private content leave the boundary: the public playtest-xtask artifact and story-check on the mirror.

### Balance work undoes itself

Each chapter's bot army is include_str!'d from one UI test fixture. #731 (a +1 Spd/Def change) re-recorded every win and knocked Ch4/Ch5 out of the bands #623 had tuned six days earlier, and it was the fourth back-in-bands ticket. The root-cause ticket 0531 has no priority, 0876 is not blocked on it, and verdicts on 100 tries sit within sampling noise.

### CI minutes go to repeats, cancels and over-broad triggers

About 49k job-minutes in a week. Playtest took 31%, 37 of its runs repeating on main a play the PR had already done. Comment-only, credits and tips edits trigger 17-job plays. Mutants cancels 37% and fails 30% of its minutes, because each fix is pushed after the first red shard. The weekly full mutants run has not finished in 8 weeks. Docs-only merges, workflow-only PRs, draft PRs and pin-only re-pins all run the full matrix. The test suite runs five times per push, binary by binary.

### Breaks are found after merge, not on the PR

#682 broke every desktop and demo export, and only a release dry run found it. The Pages workflow ran only on push, so it stayed red for 20+ pushes after #676, then was fixed (#702) and deleted (#712) a day apart. Story-kit legs were merged without ever running (#694, then #699). #627 left a stale ticket on main, and four parallel PRs each fixed it. There is no merge queue, no main-red alert, and no PR dry run for push-only or dispatch-only workflows.

### Engine pins drive the game's agenda and its perf regressions

There were 10 pin PRs in 7 days, with 44k characters of PR body copied into a 64 KB ledger. Adoptions of 4 or 20 lines each became a ticket plus a full CI PR (#734, #735). The same 12 idle adoption tickets were relisted unchanged in #700, #706 and #732, and some still list engine blockers that the pin already passed. Breaking engine changes arrive at pin time: #638 ported inks into the game, which were deleted 2 hours later, and #732 pushed the Playdate cursor sweep back over budget a week after #630 fixed it. The game's bench never runs against engine main.

### Hand-kept copies where data could be derived

shuyi.ron grew from 553 to 1,624 lines. It has four disclosure lists, every voice clip appears three times, and tests demand the lists equal computed sets. build.rs has two edition parsers plus a hand-written RON lexer. The test language pack copies all 832 UI keys. There are 7-13 quick_battle helpers and 25 shows()/row() copies. One banner rewrote 43 test files, one panel change re-blessed 57 whole-frame snapshots, and each such change can force a PR in the private repo.

### Prose and speculative tickets outweigh decisions

Ticket markdown was 31% of the window's added lines. #723 wrote 16 build tickets (2,939 lines) on four undecided 00xx decisions that wait on 0766 and 1064. Completion notes restate PR bodies, and ticket lines count toward the 3,000-line PR cap. Size estimates were written after coding (#726, #634, #676), and friction lines appear in about 60 PRs without ever firing. Starting rules for the 1064 checklist are piling up uncapped: 22 from one night.
